# 33 节点第一步：固定方案可调度域截面

本实验固定原始网架和设备，仅验证电气模型与区域构造。没有建设变量、费用或预算；结果不能称为完整可规划域。

1. 从 MATPOWER 官方数据读取 case33bw，保存原始文件及 SHA-256。采用 32 条闭合支路，5 条常开联络线保持断开。
2. 使用节点 18、25、33 的有功负荷作为三个独立坐标，均为绝对负荷 kW；其无功按原节点 Q/P 比例变化。其余节点的 P、Q 保持原始数值，不采用分区聚合或统一增长比例。
3. 沿用原始 12.66 kV、电压限值 0.9–1.1 p.u. 和电源 P/Q 限值。10 MVA 仅为标幺基准，不作为配变额定容量。线路 rateA=0 表示无热限，不补造额定电流。
4. 以独立完整 AC 支路递推核对基准潮流，并与 pandapower 的节点导纳矩阵 Newton–Raphson 潮流交叉比较。
5. 分别运行纯线性割、纯 SOCP 割和线性后 SOCP 精修。后两者复用同一个顶点迭代流程和 τ=0.002 停止精度；固定背景负荷在认证内点生成过程中也保持不变。
6. 在包含完整线性截面的共同矩形范围上作均匀网格评价，先粗后细。报告 FR、MR、完整计算时间；AC 参考扫描时间单列。每个方法重新建模，混合方法包含线性阶段。
7. 网架放在 Network/case33bw.py；与四节点共用 model.py 中的 LP/SOCP、model.py 中的独立 AC 与 vertify.py 中的比较工具，以及 plot.py 中的绘图。统一由 main.ipynb 选择网架并执行（PLANNING=False）；每次实验仅保存一个 result.npz。

模型范围为平衡、恒功率负荷、正阻抗径向网络。采用支路功率平衡与完整电压降；SOCP 放松电流—功率等式，AC 参考仍保留等式。每个样本只有在可行性或不可行性已确定时才纳入 FR/MR，不把潮流失败当作不可行。
