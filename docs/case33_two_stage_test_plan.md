# Case33bw 二维支持割与目标空间分支定界测试

## 范围

只增加测试入口与图形，不修改生产文件。沿用 37 条可重构走廊、8 个升级候选、相对投资预算 2、原始物理容差。默认坐标为节点 18、25 的有功负荷，节点 33 的有功与相应无功固定为 0；其他固定负荷不变。原模型仍有三个负荷坐标。

初始区域为 `[0,6855]^2` kW；6855 是根端有功上限扣除固定负荷后的有效上界，不是将功率基值当成变压器容量。

## 数学步骤

1. 全局支持割：在全部整数建设方案和完整 SOCP 运行约束中最大化非负加权负荷。只使用全局 `ObjBound` 裁剪外域；保留支持方向、上下界、原始可行证书、耗时和每一步多边形。先使用轴向、总量和若干斜向支持，再按外域与已知支持点凸包之间的间隙补充方向。第一阶段只能逼近凸包。
2. 目标空间分支定界：节点是第一坐标区间 `[a,b]`，其外界是第一阶段多边形与 `p2 <= U` 的交。内域是同一完整网架下认证点的向下凸包的并集；对每个节点计算覆盖整个节点的认证距离上界，选最大者。查询 `max p2, p1 >= t`，所有网架仍在同一个整数模型中。纯负荷向下封闭性允许等价固定 `p1=t`。全局上界允许删除 `p1 >= t, p2 > U(t)`；可行点扩充内域；左右子区间进入队列。认证间隙不超过预设 kW 容差才停止。
3. 独立参考：另建完整规划模型，在规则网格上逐点判断。固定网架独立 AC 潮流只提供可行证据；整体不可行必须由全网架模型证明。利用纯负荷向下封闭性减少重复整数求解，但保留每个网格点的三态标签与证书来源。不能只扫描第二阶段找到的网架后称其为实际规划域。
4. 几何与数值审核：全部内点满足预算、径向性和独立 AC；支持割不得排除参考可行点；逻辑割不得排除适用区间内的参考可行点；几何误差与网格间距分别报告。未决点与求解时限不等于不可行。

此原型是目标空间分支定界，加上每个定界问题内部的整数分支定界；并非完整移植 MOMIX，也不声称跨查询共享 Gurobi 搜索树。模型对象和可行起点可复用。

测试模型加入与原整数树等价的根向父弧和多类连通流扩展，以加强连续松弛；纯负荷方向功率不等式和电压不高于根电压也是有效加强。已知网架先作连续 SOCP，得到完整可行初值，只作为全网架搜索的起点。没有用这些固定网架取代全局定界。数学映射见 `docs/notation.md` 第 15 节。

调试运行保存为 `pilot`，定型后的脚本从空状态重新运行 `run`，最终作图使用后者。独立扫描使用单独种子、模型和证书，可保留已完成列继续；不导入构域结果。两个任务重叠运行时线程总数限制为 24，并在报告记录，耗时不作为严格算法加速对比。

默认先以 20 kW 认证容差构域，再以 5 kW 网格参考核验；如计算需要分阶段，保留更细容差的继续求解记录。记录完整耗时，不预先承诺加速。运行前做求解探测与合成非凸域回归，运行后做符号契约测试和图形检查。
