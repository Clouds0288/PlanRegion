# Case33 正负接入实验

```powershell
python experiments/case33_signed.py
```

默认依次计算二维 `(18,25)`、三维 `(18,25,30)`，构域总上限分别为60秒、300秒。全部符号分区共用上限；独立扫描与网页导出另计时间。可以用 `--dimension 2` / `--dimension 3` 单独运行，`--seconds` 覆盖时间。

1. MODE=1：正有功是负荷，PF=0.95；负有功是光伏输出，PF=1。未选节点保留 Case33 原始背景负荷。
2. 保留原来的7个开关变量和7次开合预算，仍要求全网径向连通。原数据没有线路额定容量，不添加假定限额；用电压和全网无功平衡推导有效变量界。接根支路允许反向有功潮流。
3. 每个固定符号区内逐网架构域；内域按同网架认证点取凸包，跨网架、跨符号区取并集。Case33 的零接入点也实际求解认证。
4. 二维每轴160格，三维每轴80格。扫描独立求解完整SOCP；同一符号区内若一段的两端由同一网架认证，则利用凸性认证中间格点，其余二分检查。不可行格点均实际求解，不使用构域结果推断。MR=参考可行但认证域未覆盖的格点数/参考可行格点数；FR=认证域覆盖但参考不可行的格点数/认证域覆盖格点数。它们是离散SOCP比较，不是非凸AC真值误差。
5. 结果保存在 `results/case33_signed/mode_1/18_25/` 和 `18_25_30/`。双击 `replay.html` 即可离线播放，也可从记录重新导出：

```powershell
python experiments/case33_signed.py --replay results/case33_signed/mode_1/18_25_30/recording.json.gz
```

构域结束即生成回放，可在扫描期间查看 G、G′、Nₓ、N′ₓ、检查点、射线和最近一条割，支持暂停、逐帧、拖动进度、网架切换和三维旋转。扫描完成后刷新网页即可查看参考域及误差。`recording.json.gz` 保存原始迭代数据，HTML只用于查看。

扫描缓存位于 `results/scans/case33_signed/`，按节点、模式、功率因数、预算分目录/文件名；功率范围包含本次需求时复用。`--force-rescan` 强制重算，不使用哈希。主线入口及物理模型文件不修改。
