# Case33bw 三维、三预算两阶段构域测试

## 问题与配置

比较相对建设预算 0、2、4 下的三维负荷规划域，坐标 `(p18,p25,p33)`，单位 kW。8 个候选升级项目，37 条走廊；原生产模型与源数据不修改。三个预算独立构域，保留所有允许的径向网架。初始区域为 `[0,6855]^3` 立方体，6855 是源端有功上限扣除其余固定负荷的必要总量上界，不是 MATPOWER baseMVA 自动定义的变压器铭牌容量。

升级候选为 2–3、5–6、12–13、13–14、23–24、24–25、27–28、28–29。2–3 费用为 2，其余每条为 1；并联档位将电阻、电抗减半。原 Case33bw 的 rateA 为 0，表示没有给定线路热额定值，代码按无限额处理，本实验不另行虚构热限额。其他节点负荷保持固定，开关重构不计投资费用。

三维认证误差 20 kW（有向无穷范数；三个坐标可共同变化），独立截面采用 10 kW 网格。暂定共同截面 `p33=0,500,1000` kW，先用三个轴方向探测确认是否覆盖从低负荷到边界的有效范围；如有截面为空，原样展示。

## 算法和调用

独立测试模块 `tests.case33_3d` 的调用关系为 `main → construct → PlanningOracle3D.solve → Gurobi optimize`。几何计算直接调用 `scheme_hulls/cell_gap/subtract_disjunction/cover_partition`；截面直接由 `scan_slice → PlanningOracle3D.solve` 求解。复用既有测试中的树扩展松弛、序列化、独立物理审核，以及生产模型装配和几何裁剪，不修改它们。

第一阶段对非负方向 omega 求完整 MISOCP 的 `max omega @ p`，以全局 ObjBound 上界切平面。先求三个坐标轴，再按当前凸包支持间隙自适应选择方向。保存每个平面的方程、全局界、求解时间和证据；所得 O1 为全局凸外近似。

第二阶段在目标空间的凸多面体节点上分支定界。对每个节点、每个已发现网架的凸内域，计算全部顶点到该内域的最大无穷范数距离；再在网架之间取最小值，得到整个节点的安全距离上界。始终选择当前最大认证间隙节点。

对该节点上未覆盖候选 q，求 `min distance_kw`，满足原完整 MISOCP、`p_i + distance_kw >= q_i` 和 `distance_kw >= 0`。该问题的所有建设变量均自由；下界 d_lower 产生析取割 `OR_i p_i <= q_i-d_lower`，等价于去掉一个已证不可行的右上正交象限。新可行点补充同网架凸内域。析取分解最多三个内部不交的凸子节点。若顶点已由不同网架覆盖而整个节点尚未被一个凸内域覆盖，做几何二分，继续认证；绝不把跨网架凸包当成可行域。

三维加速采用可选斜向析取：取最多三个非负、和为 1 的法向组成 W，求完整规划模型下 `min projected_deficit_kw`，约束 `W @ p + projected_deficit_kw >= W @ q`。全局下界 rho_lower 产生 `OR_k W[k] @ p <= W[k] @ q-rho_lower`。这是正交象限割的推广；斜向目标不是 L∞ 距离，最终停止仍用原始全节点距离证书。若斜向查询没有有效正下界，则回退到正交查询。方向来自同方案凸内域的活动面，只用于选方向；所有 cut 均由全局问题定界。两种割同样传播至所有相交节点。

内域扩张只会降低节点上界，因此选点先复核缓存最大者；若其更新后仍不小于其他缓存上界，它必然是当前真实最大认证间隙节点。这与每轮全量重算等价，最终离线仍重算全部叶节点。固定已知方案得到距离小于 19.999 kW 的可行点时，可只扩充内域，跳过全整数查询；这种结果没有全局下界，不产生割。

当顶点已分别覆盖、全节点距离仍未达标时，可沿同一方案内域的 20 kW 距离邻域分支。若内域面为 `a @ p <= b`，邻域由所有非空坐标掩码 S 的 `a_S @ q <= b + epsilon_kw * sum(a_S)` 描述；保留邻域内外全部子节点，不删除体积。覆盖子节点仍由原距离函数重新认证，无法有效分割时回退至最长坐标边二分。该分支只加快跨方案覆盖证明，不产生不可行性割。

覆盖部分必须与父节点具有相同仿射维数。仅在边界接触时，拒绝会留下原节点不变的覆盖分支，改试其他方案或几何二分；已有边界点仍然保留。回归同时检查三维体积守恒、低维截面分割和相切节点的进展。

当全部节点距离上界不超过 20 kW 时，才标记 certified。这里认证针对 SOCP 投影，全部保留端点另经 AC 校核。独立 10 kW 截面用于报告与 AC 真值参考的差异，不把少量切片外推为完整三维 AC 扫描。超时和数值不确定保持 unknown。

## 独立验证

每个预算三个固定 p33 截面，从原模型重新开始，不导入构域的割、网架或证书。按 p18 网格列求最大 p25，以全局上界排除其上的网格点，以独立 AC 逐点验证可行点；边界未确定点再做固定负荷完整 MISOCP。保存每列证书、全部三态网格和所有查询日志。

未知区间以二分点查询收紧；某个点超时仍保持 unknown。对应扫描进程结束后，`repair_case33_3d_slice` 可用不含树扩展松弛的原始 MISOCP 单独复核剩余未知点，保留独立证据。审计同时从支持上界、已证不可行点和必要界重建全部不可行网格分类，检查它们与 AC 可行分类没有冲突。

同一独立扫描中，固定 p33、按递增 p18 查询，可以复用已证明的 p25 上界收紧后续查询模型；该条件上界不进入完整三维构域。热启动按固定坐标的偏差优先排序，再比较目标值，以优先使用相邻列的已知方案。所有网架仍由全局问题自由选择。

若原始固定点复核仍未得到证据，可用 `recheck_case33_3d_columns --index <列下标>` 重新求该列的全局 p25 上界。固定方案副本充分求解后只提供热启动，最终查询中全部建设变量保持自由。不同列输出独立证据文件，查询完成后通过该模块的 `--merge <证据文件...>` 顺序合并；重新构建全部不可行分类证明并检查不与已知可行点冲突。并行复核的计时取活动时段并集，不重复累加重叠时间。

数值回归包括：三维几何的坐标面、析取分割体积守恒、跨方案顶点覆盖反例、距离与 LP 的独立比对、原模型和树加强模型固定方案一致性、所有支持割/析取割不误删已知可行证据、预算集合的理论嵌套、每个叶节点的覆盖证书重算、所有截面可行网格点 AC 回放、生产源文件散列不变。

## 图形契约

核心问题：增加建设预算如何改变三维规划域，以及两阶段方法能否在全域误差受控的同时保留非凸边界。

1. 可旋转三维 HTML：预算切换、初始立方体/阶段一/阶段二切换、每一步的切面与公式、红色半透明阶段一切除、红色斜纹阶段二切除、蓝色虚线外包络、绿色虚线最终外域。三维斜纹以真实切除片上的显式线段表示，避免将未扫描空间画成真值。
2. 固定 p33 截面图：按同一物理坐标比较三个预算。红色短虚线为 `Actual region — independent 10 kW grid`，蓝色虚线 O1，绿色虚线 O2；浅红填充和红色斜线分别表示两阶段切除。
3. 收敛图与预算体积比较：显示认证间隙、全局查询数、时间和外域体积；体积是认证外近似体积，不冒充精确可行体积。

静态图使用 Python，输出 PNG/PDF/SVG 及源数据。可比较子图保持相同轴限和物理尺寸；保留面板对齐、PDF 字形与碰撞检查，以及实际视觉核查记录。交互图额外核查旋转、预算选择、阶段切换及截面控制。

切面表为每面一行：`stage,index,facet,w18,w25,w33,threshold_kw,global_deficit_kw`。第一阶段每个 index 对应单个支持不等式；第二阶段同一个 index 的各行以 OR 连接。三维回放仅压缩重复顶点和相邻帧未变化的面，不省略任何一次有效切割。

本次计时来自带检查点的增量实验，各预算会并行；报告分别给出累计构域时间、截面时间与日志记录的运行区间，不把并行任务时长相加称为墙钟时长。中预算 p33=0 截面由同源原模型的历史独立 5 kW 网格抽取 10 kW 子网格，并保留源文件散列和原始耗时；不重复声称为新计算。
