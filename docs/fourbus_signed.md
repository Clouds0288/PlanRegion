# FourBus 固定功率因数正负接入实验

入口为 `experiments/fourbus_signed.py`，主线 `main.py`、`model.py` 的默认模型保持不变。需要现有 methods 环境中的 Gurobi、Clarabel、NumPy、SciPy、Plotly 和 threadpoolctl。

## 1. 模型与流程

MODE=0 计算原正负荷域；MODE=1 使用同一个带符号功率 p：正值为负荷，负值为光伏。默认负荷功率因数0.95，光伏功率因数1；不新增逆变器容量圆，保留原源端容量与线路物理约束。根支路允许倒送。

二维节点为(1,2)，三维为(1,2,3)。按功率符号分别计算4个或8个凸分区，每个分区内部沿用“初始化支撑—首轮射线—最大违反点切割—边界补充—完整物理查漏”。认证域只按相同符号和相同网架取凸包，最终跨组取并集。

SP 和射线由连续锥求解器求解，割仍由原 LP 生成，完整网架搜索仍由原混合整数 SOCP 求解。固定变量和恒成立的开断线路锥在连续求解前解析消去。射线直接代入功率表达式，并对锥作1e-6标幺的微小保守内缩；原物理残差认证门槛保持1e-8。局部点增加、有效割和全局覆盖证明分别核验，不把局部求解状态当作全局停止证书。

## 2. 运行

```powershell
conda activate methods
python experiments/fourbus_signed.py
```

默认依次运行 MODE=1 的二维与三维。全部符号分区共用20秒或60秒构域上限；参考扫描和网页导出另计。

```powershell
python experiments/fourbus_signed.py --dimension 2 --seconds 20
python experiments/fourbus_signed.py --dimension 3 --seconds 60
python experiments/fourbus_signed.py --dimension 3 --force-rescan
```

功率因数、MODE、时间、线程、射线收益阈值和扫描参数均放在实验入口开头。`RAY_THRESHOLD=1e-4` 表示几何收益上界不足本网架认证面积/体积的0.01%时省去补充射线；首轮射线不受此筛选。

## 3. 结果与回放

每组结果位于 `results/fourbus_signed/mode_1/1_2/` 或 `1_2_3/`，包含原始增量记录 `recording.json.gz`、离线回放 `replay.html` 和配套 `plotly.min.js`。直接打开网页，或运行：

```powershell
python experiments/fourbus_signed.py --replay results/fourbus_signed/mode_1/1_2/recording.json.gz
python experiments/fourbus_signed.py --replay results/fourbus_signed/mode_1/1_2_3/recording.json.gz
```

回放支持播放、逐帧、拖动进度、网架选择和三维旋转；展示 G、G′、Nₓ、N′ₓ、SP点、割和射线。最后一幅比较最终计算域与独立参考扫描。

## 4. 参考与指标

二维采用160²格点，三维80³格点，在网格中心逐点开放全部合法网架求解完整 SOCP。扫描不使用算法割、已知网架或认证凸包；目标为判断是否存在可行解，无需额外求最小投资。数值失败直接报错，不记作不可行。

扫描保存于 `results/scans/fourbus_signed/mode_1/节点序列/pf_0.95_1_+1_budget_20000.npz`。只按模型配置目录和功率范围包含关系复用，不使用哈希；修改物理参数后使用 `--force-rescan`。改变格数也需强制重扫才会替换已有网格。

- 遗漏率 MR = 参考可行、计算域未覆盖的格点数 / 参考可行格点数。
- 多余率 FR = 计算域覆盖、参考不可行的格点数 / 计算域覆盖格点数。

这些比例是均匀网格对面积/体积比例的估计。参考是同一 SOCP 松弛模型，未作为非凸 AC 真值；倒送情况下不能据此宣称 SOCP 松弛已验证精确。

## 5. 验证

```powershell
python -m unittest tests.test_fourbus_signed tests.test_notation -v
```

覆盖正区间与原模型的一致性、有功/无功符号、跨网架割有效性、退化 SP、三维射线、坐标转换、扫描对照、指标和符号约定。
