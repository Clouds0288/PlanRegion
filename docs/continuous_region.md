# 方向 MP2 / SP 连续构域

符号、代码名、单位和数组顺序以 [数学符号与代码变量规范](notation.md) 为准。归一化坐标记为 \(\xi\)，\(z\) 留给走廊接通状态。

本实现构造负荷空间中的连续集合。`main.build_continuous_region` 集中写出 **1 初始化 → 2 选点 → 3 全局搜索 → 4 SP 更新 → 5 汇总**。每轮最多调用一次 SP 或剩余域模型；方向 MP2 在循环前完成。`model.py` 只建模和单次求解，`region.py` 只计算二维或三维几何，`vertify.py` 在完整构域后做独立 AC 校核。`plot.py` 整理结果和绘图，`monitor.py` 记录步骤和提供单步控制；二维道路勘察见 [勘察模型与结果](survey.md)。

## 集合与整数方案

对于预算 \(\mathcal B\)，目标是所有合法线路选型 x 下连续物理可行负荷集合的并集。每个固定 x 的 LP/SOCP 约束关于运行变量和负荷都是凸的，因此该方案下经 SP 认证的负荷点凸包是有效内域。不同方案只能取并集，不能直接对所有点取凸包。

正式算法保留完整型号向量与根树约束。所有算例均可重构；测试侧的四升级组合枚举仅适用于显式固定初始拓扑的历史基准。

## MP1、MP2 与 SP

- **方向 MP2 初始化**：预算内依次最大化每个 p_i，再最大化总负荷，其他负荷始终自由。每个全局上界用于建立 `axis_bounds` 或 `total_bound`；每个完整可行解立即加入对应网架内域。二维共 3 次，三维共 4 次，不默认调用 MP1。
- **MP1**：仍保留固定负荷/最低总负荷下最小投资的能力，供定点诊断与独立查询使用，不进入构域初始化。
- **SP 顶点认证**：候选先经过全局认证内域并集筛选。其他方案已覆盖的普通候选直接跳过，不加入当前方案的内域。其余候选由 SP 认证，可行点扩大本方案内域；有效联合割裁剪所有方案的外域。
- **残余区域主问题**：检查当前内域并集是否覆盖整数联合外域，同时返回未覆盖负荷和线路方案。未发现方案始终保留在整数搜索中。
- **内部空隙支撑证书**：全局见证可能位于外域内部，即使外域所有顶点分别被不同方案覆盖，内部仍可有空隙。将见证放入该方案收缩外域的单纯形（至多 d+1 点）中；仅对缺少当前方案证书的支撑点调用 SP。部分支撑点可能已被其他方案覆盖，此处的认证是为扩展当前方案内域、填补已确认的空隙。测试独立核对候选筛选、证书归属和单纯形覆盖。新割排除原见证后立即丢弃过期支撑点。

普通选点在 `main.py` 中枚举所有已知网架的未覆盖外域顶点，以 `point @ bounds` 即实际 kW 总量排序。`tau>0` 检查收缩后的对应点；内部见证的支撑点不要求都是顶点，按同样的实际负荷规则优先检查。普通候选为空，或活动见证处理完且累计 96 次 SP 后，显式调用全局剩余域模型。几何半空间和包围盒仍按域更新缓存。

`MasterProblem` 通过 `direction` 设置 MP2 目标，通过 `power/min_total` 选择成本最小化问题。方向初始化不传 `incumbent`，避免其附加的成本上界限制其他方向；任一后续方向失败前，已完成方向的证书已经记录。AC 校核通过 `vertify.ac_planning_query` 搜索方案。一个最大总负荷点不能代替整个连续域。

`bounds` 保留为公共正数归一化箱；`axis_bounds` 是本预算下紧的坐标上界。初始外域为 `0 <= p <= axis_bounds` 与 `sum(p) <= total_bound` 的交集，新网架外域和最终外包络也受这些约束。方向上界之间的箱角不自动获得认证，不同网架的初始化点不混合取凸包。

## 全局覆盖证书

在公共评价箱归一化坐标 \(\xi=p\oslash b^{\rm box}\) 中，方案 x 的已认证内域写为

\[
I_x=\{\xi:F_x\xi+g_x\le0\}.
\]

令 \(s_\tau=1-\tau\)。残余主问题在包含所有整数方案的搜索域上求（light 使用联合割外域，physical 还加入完整运行约束）

\[
\max_{x,p}\min_{x'\in\mathcal X_{\rm known}}\max_f
\{F_{x',f}s_\tau(p\oslash b^{\rm box})+g_{x',f}\}.
\]

每个内域用一个二进制选面约束表示最大面违反量；大 M 从归一化单位箱的精确线性下界推导。该 MILP 的**全局上界**不超过 `GEOMETRY_TOL=1e-8`，才证明所有整数方案的收缩外域被已认证内域的容差扩张覆盖。

残余 MILP 对割和距离变量进行正比例数值缩放（距离放大 1000 倍，返回时还原）。约束集合、目标顺序和覆盖容差保持不变，避免绝对数值误差产生位于已覆盖区域内的伪见证。

探索阶段设置正的目标停止阈值：找到足够明确的未覆盖见证即可返回，不必每轮证明它是最远的点。终止构域仍检查求解器全局上界；找到见证与证明全域覆盖是两种不同的停止条件。

MP/SP 共用具名的 `x[e,k]`、`P[e,k]`、`Q[e,k]`、`ell[e,k]`、`v[i]` 约束。SP 用 Gurobi 最小化功率平衡与压降等式的松弛量；所有不等式和电流锥保持严格。SP 求解达到 `OPTIMAL` 后，若 `max(0, eta.X) + model.MaxVio <= PLANNING_TOL`，直接接受原始状态；若精度合格且 eta 为正，则用锥支撑平面的 LP 对偶生成分离割。这是不可行点取割的正常算法步骤。求解异常、精度不足或无法生成有效割均报错。全过程不改变负荷或方案，求解与取割共享原 SP 时限。

这样不会把“没有找到更多方案”误当作证明，也不会把已发现方案的外域并集误当作全部方案的外域。求解超时或无法获得证书时直接报错，保留过程日志，不返回完成结果。

## 可显示的全局外包络

对满维内域 I 的严格内点 \(\xi_c\)，令 \(r_{\rm in}\) 为它到最近归一化面的距离。定义

\[
I^{\rm env}=\xi_c+(1+\varepsilon_{\rm geom}/r_{\rm in})(I-\xi_c),\qquad
\varepsilon_{\rm geom}=10^{-8}.
\]

\(I^{\rm env}\) 包含将 I 每个面向外移动 \(\varepsilon_{\rm geom}\) 后的集合。覆盖证书因此保证真实域被各 \(I^{\rm env}/s_\tau\) 的并集包含；再与本预算坐标上界及总负荷有效上界相交，得到最终蓝色外包络。低维集合采用逐面裁剪的退化处理。

绿色为已认证内域并集，蓝色为上述全局外包络。体积计算扣除方案间重叠，不把各方案体积直接相加。LP 取 tau=0，SOCP 默认 tau=0.002。三维径向放大的理论体积间隙约为 `1-(1-tau)^3=0.598801%`，实际报告使用内外域并集的计算体积，并包含几何数值容差。最大总负荷直接使用求解器结果，另保留可行下界及全局上界；`radial_gap_kw=0.001` 仅用于目标间隙判定，不再内缩负荷。

这些是当前 LP/SOCP 模型在所报告数值容差下的证书。AC 等式模型另行校核，不因 SOCP 认证而自动视为 AC 全域认证。

## 混合方法和 AC 校核

LP→SOCP 包含自身的 LP 阶段，再将有效 LP 割传给 SOCP；LP 内域不能用于 SOCP 认证。每档预算独立计算，不维护跨预算证书缓存。结果保存网架指纹，用于读取时核对数据口径。混合方法的总耗时和 SP / 割次数包含两个阶段，两阶段共享构域时限。

连续构域完成后才按 `DIVISIONS` 生成公共中心网格，内域为 1、外包络之外为 −1、之间为 0。独立 AC 方案搜索得到参考标签，计算保留内域与 AC 域的对称差/并集体积误差及多算、漏算比例；AC 不收敛则报错，尚未纳入内域的薄层按未保留处理。历史结果中的 AC 未知标签仍可读取。更改网格分辨率不改变连续域，只改变校核样本和 AC 阶段时间。

历史 Case33 四升级审核使用固定初始树的 16 种线路组合，不能覆盖当前完整重构空间。完整模型的有效割通过全局最小余量检查，FourBus 另穷举全部 216 个树与型号组合核对独立 LP/SOCP。全域覆盖仍以上述整数主问题证书为依据。

## 最终结果与时间口径

`result.npz` 保存三态网格和必要元数据。各方案认证内域以 kW 顶点、方案选型和投资保存一次；全局外包络独立保存。最终结果保留割数量，选点、割和包络变化记录在同一运行目录的 `steps.jsonl`，供实时查看与回放。

构域入口返回原始数组和求解结论，序列化与网格采样由 `plot.py` 完成。
并集体积及体积间隙通过 `plot.region_metrics(result, bounds)` 按需计算；FR/MR 和误差区间由 `BenchmarkResult.summary` 推导，不重复保存到每个域记录中。

构域总时间包含建模、求解和几何计算；AC 时间单列。公共评价箱准备、结果采样整理、绘图和导出不计入构域时间。`SHOW_UI=True` 启动实时窗口并保存自包含 HTML；计算完成后可回放，终端按 Enter 关闭服务。

旧 HTML 和回放仍可独立读取。`monitor.RunMonitor` 通过进度回调记录展示事件，不参与求解和认证；并集覆盖回归保留在 `tests/test_union.py`，一次性审核脚本已移入项目外归档。

## 完整主问题与剩余域选项

主线直接创建 `MasterProblem` 并调用 `solve` 求解完整方向 MP2。求解达到 `OPTIMAL` 或算法设定的目标停止条件，且数值质量满足容差时直接复用证书；其他求解状态和精度不足均报错。历史联合割查询的比较函数 `joint_benders` 与手工约束代入检查均保留在 `tests/planning_checks.py`，仅用于回归；临时 benchmark 入口已归档。

查询直接返回答案；`None` 表示已证明不可行。SP 只返回 `feasible`、`state` 和 `cut`；没有运行证书或有效割则报错。旧基准的“答案＋新割”返回格式仅由测试侧适配。

求解器统一默认 20 线程，可由调用参数覆盖。MP、LP/SOCP SP 和剩余域单次时限集中在 `model.py`，AC 的迭代上限、非凸求解时限及认证容差集中在 `vertify.py`。SP 取割共用该次 SP 的剩余时限，运行解接受标准和对偶割有效性分别判断。

顶部参数 `RESIDUAL_MODE` 支持 `auto`、`light`、`physical`。auto 对有限预算选 light，对无限预算选 physical。两种模式使用相同的预算、全局有效割、连续内域并集排除约束和归一化覆盖阈值；区别是 physical 还带完整运行约束。其整数见证的求解器数值质量满足接受容差后可成为内域种子。割后的顶点仍可能只属于外松弛，不能一概省略认证；同方案已有证书和合法预算内其他方案已覆盖的普通点则不再重复 SP。

停止依据仍为剩余域全局目标上界或明确不可行证书。没有普通候选只触发全局检查，不表示完成；求解失败直接抛出，不增加自动重试或替代点规则。每档预算记录坐标上界、最大总负荷、内外域、认证结论、总耗时和 SP / 割次数；步骤日志不重复保存运行向量和割。默认入口仅执行 SOCP 和结束后的 AC，报表不显示未运行的方法。
