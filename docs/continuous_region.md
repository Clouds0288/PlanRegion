# MP1 / MP2 / SP 连续构域

本实现构造负荷空间中的连续集合。`main.solve_region` 明确组织 MP2 → MP1 → SP 与全局覆盖循环；`model.py` 构建优化模型并完成单次主问题查询；`region.ContinuousRegion` 提供认证、裁剪与剩余域搜索操作，`RegionState` 管理三维域及候选点。`vertify.py` 负责最终独立 AC 校核，`plot.py` 负责结果整理、存取和最终 HTML。

## 集合与整数方案

对于预算 B，目标是所有合法线路选型 x 下连续物理可行负荷集合的并集。每个固定 x 的 LP/SOCP 约束关于运行变量和负荷都是凸的，因此该方案下经 SP 认证的负荷点凸包是有效内域。不同方案只能取并集，不能直接对所有点取凸包。

正式算法保留逐线路整数变量，不事先枚举 16 个组合。测试侧独立审核会穷举四候选的全部组合，用于发现遗漏和核对边界。

## MP1、MP2 与 SP

- **MP2**：在预算内最大化三个独立节点的总负荷。整数主问题含逐线路选型、预算及完整运行约束；解通过原始方程复核后直接提供证书，数值未获证才补充 SP。
- **MP1**：最小化投资，约束总负荷不低于 MP2 已认证的总量，允许三个节点重新分配。已知 MP2 可行解作为 incumbent；当 MP1 全局下界达到该投资时，可以证明最优而不必重复寻找边界点。
- **SP 顶点认证**：候选先经过全局认证内域并集筛选。其他方案已覆盖的普通候选直接跳过，不加入当前方案的内域。其余候选由 SP 认证，可行点扩大本方案内域；有效联合割裁剪所有方案的外域。
- **残余区域主问题**：检查当前内域并集是否覆盖整数联合外域，同时返回未覆盖负荷和线路方案。未发现方案始终保留在整数搜索中。
- **内部空隙支撑证书**：全局见证可能位于外域内部，即使外域所有顶点分别被不同方案覆盖，内部仍可有空隙。将见证放入该方案收缩外域的单纯形（至多四点）中；仅对缺少当前方案证书的支撑点调用 SP。部分支撑点可能已被其他方案覆盖，此处的认证是为扩展当前方案内域、填补已确认的空隙。测试独立核对候选筛选、证书归属和单纯形覆盖。新割排除原见证后立即丢弃过期支撑点。

局部每批最多处理 96 个候选，然后返回全局搜索。几何半空间和包围盒按域更新缓存；进展使用几何版本而非顶点数量，避免新顶点替换旧顶点后误判停滞。

`model.planning_query` 提供自由最大总负荷、固定负荷最低投资和最低总负荷三类查询。AC 校核通过 `vertify.ac_planning_query` 搜索方案。一个最大总负荷点不能代替整个连续域。

## 全局覆盖证书

在公共评价箱归一化坐标 z 中，已认证内域写为

\[
I_i=\{z:A_i z+b_i\le0\}.
\]

令 s=1−tau。残余主问题在包含所有整数方案的搜索域上求（light 使用联合割外域，physical 还加入完整运行约束）

\[
\max_{x,p}\min_i\max_f\{A_{if}s(p/\mathrm{bounds})+b_{if}\}.
\]

每个内域用一个二进制选面约束表示最大面违反量；大 M 从归一化单位箱的精确线性下界推导。该 MILP 的**全局上界**不超过 `GEOMETRY_TOL=1e-8`，才证明所有整数方案的收缩外域被已认证内域的容差扩张覆盖。

残余 MILP 对割和距离变量进行正比例数值缩放（距离放大 1000 倍，返回时还原）。约束集合、目标顺序和覆盖容差保持不变，避免绝对数值误差产生位于已覆盖区域内的伪见证。

探索阶段设置正的目标停止阈值：找到足够明确的未覆盖见证即可返回，不必每轮证明它是最远的点。终止构域仍检查求解器全局上界；找到见证与证明全域覆盖是两种不同的停止条件。

SP 在 phase I 数值停滞且既无可行证书也无有效割时，以零锥表达原始等式进行复核。此复核不改变负荷、方案、物理约束或 `PLANNING_TOL`，与后续复核共享原 SP 时限；只有原始约束余量合格才接受。

这样不会把“没有找到更多方案”误当作证明，也不会把已发现方案的外域并集误当作全部方案的外域。残余问题超过时限但尚无覆盖证明时，状态为 `unknown`，返回保守公共外域。

## 可显示的全局外包络

对三维内域 I 的严格内点 c，令 r 为 c 到最近归一化面的距离。定义

\[
J=c+(1+\varepsilon/r)(I-c),\qquad \varepsilon=10^{-8}.
\]

J 包含将 I 每个面向外移动 epsilon 后的集合。覆盖证书因此保证真实域被各 J/s 的并集包含；再与公共评价箱及总负荷有效上界相交，得到最终蓝色外包络。低维集合采用逐面裁剪的退化处理。

绿色为已认证内域并集，蓝色为上述全局外包络。体积计算扣除方案间重叠，不把各方案体积直接相加。LP 取 tau=0，SOCP 默认 tau=0.002。三维径向放大的理论体积间隙约为 `1-(1-tau)^3=0.598801%`，实际报告使用内外域并集的计算体积，并包含几何数值容差。最大总负荷另外保留可行下界及全局上界；边界内缩约 0.001 kW。

这些是当前 LP/SOCP 模型在所报告数值容差下的证书。AC 等式模型另行校核，不因 SOCP 认证而自动视为 AC 全域认证。

## 混合方法和 AC 校核

LP→SOCP 包含自身的 LP 阶段，再将有效 LP 割传给 SOCP；LP 内域不能用于 SOCP 认证。每档预算独立计算，不维护跨预算证书缓存或模型指纹。混合方法的总耗时和 SP / 割次数包含两个阶段，两阶段共享构域时限。

连续构域完成后才按 `DIVISIONS` 生成公共中心网格，内域为 1、外包络之外为 −1、之间为 0。独立 AC 方案搜索得到参考标签，计算保留内域与 AC 域的对称差/并集体积误差及多算、漏算比例；AC 未知标签保留区间，尚未纳入内域的薄层按未保留处理。更改网格分辨率不改变连续域，只改变校核样本和 AC 阶段时间。

当前 case33 四候选审核使用 16 种线路组合、7 个支持方向的 LP/SOCP 独立模型、所有已保存内域顶点，；有效割由模型回归测试在完整规划可行域上检查全局最小余量。AC 对全部方案和全部公共网格中心独立计算，与正式方案搜索及单调传播标签逐项核对。这些测试核对实现；全域覆盖依据仍是上面的整数主问题证书。

## 最终结果与时间口径

`result.npz` 保存三态网格和必要元数据。各方案认证内域以 kW 顶点、方案选型和投资保存一次；全局外包络独立保存。有效割只在求解期间维护，结束后仅保留数量。没有逐查询日志、阶段计时、事件快照或跨预算复用记录。

`region.py` 返回原始数组和求解结论，序列化与网格采样由 `plot.py` 完成。
并集体积及体积间隙通过 `plot.region_metrics(result, bounds)` 按需计算；FR/MR 和误差区间由 `BenchmarkResult.summary` 推导，不重复保存到每个域记录中。

构域总时间包含建模、求解和几何计算；AC 时间单列。公共评价箱准备、结果采样整理、绘图和导出不计入构域时间。`SHOW_UI=True` 生成自包含的最终 HTML，程序随即退出。

旧 HTML 和回放仍可独立读取。`plot.RunMonitor` 与 `tests.audit_union` 仅服务于历史记录的展示、验证，不再接入正式求解流程。

## 完整主问题与剩余域选项

主线 `planning_query` 直接求解完整 LP/MISOCP 的 MP2、MP1。它将整数选型、负荷与运行状态代回原方程；满足原始可行性容差时直接复用证书，数值未获证才调用 SP。旧联合割主问题仅留在 `tests/benchmark_physical_search.py` 作为历史算法对照。

查询直接返回答案；`None` 表示已证明不可行。SP 只返回 `feasible`、`state` 和 `cut`；没有证书和有效割时保持未确定。旧基准的“答案＋新割”返回格式仅由测试侧适配。

求解器统一默认 20 线程，可由调用参数覆盖。MP、LP/SOCP SP 和剩余域单次时限集中在 `model.py`，AC 的迭代上限、非凸求解时限及认证容差集中在 `vertify.py`。边界精修共用原 SP 的剩余时限，原始可行性和对偶割有效性仍各自核验。

顶部参数 `RESIDUAL_MODE` 支持 `auto`、`light`、`physical`。auto 对有限预算选 light，对无限预算选 physical。两种模式使用相同的预算、全局有效割、连续内域并集排除约束和归一化覆盖阈值；区别是 physical 还带完整运行约束。其整数见证也必须通过原方程复核才能成为内域种子。割后的顶点仍可能只属于外松弛，不能一概省略认证；同方案已有证书和合法预算内其他方案已覆盖的普通点则不再重复 SP。

停止依据仍为剩余域全局目标上界或明确不可行证书。没有候选、局部无进展或达到时限都不能证明全域完成。每档预算只记录总构域时间及 SP / 割次数，不再保存重叠的分项计时。
