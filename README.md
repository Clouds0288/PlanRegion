# 配电网可规划域

唯一运行入口是 **main.ipynb**。四节点五走廊是长期保留的基础测试网架；case33bw 是规模扩展网架。两个算例共用逐线路 MILP/MISOCP、联合割、独立 AC 和构域流程，不预先生成建设组合表。

| 文件 | 职责 |
|---|---|
| `Network/` | 基础网架、固定负荷、独立负荷节点、升级选项与费用 |
| `model.py` | `PlanningEquations`、`PlanningModel`、`PlanningSP`、`ACPowerFlow` 四个模型类 |
| `main.ipynb` | 初始化、联合割查询、独立 AC 方案验证、区域构造、计时与展示 |
| `region.py` | 纯负荷单调域的成块分类和网格二分 |
| `vertify.py` | 独立潮流交叉核验、FR/MR、三态标签及单文件存取 |
| `plot.py` | 从已有标签绘制同步旋转的三维对比图 |
| `tests/` | 模型、割、AC 和区域回归；外部看门狗仅供测试使用 |

## 运行

使用安装了 `requirements.txt` 的 Python 内核，从头执行 `main.ipynb`：

```python
network = Case33(candidate_count=16)  # 当前十六候选测试；可改为 4 或 8。
# network = FourBus()             # 保留的基础四节点五走廊。
BUDGETS = network.budgets        # 默认预算与费用单位均来自 Network。
DIVISIONS = 8                    # 当前十六候选测试：三个负荷轴各划分 8 个单元。
RECOMPUTE = False                # 读取本轮结果；改为 True 重新计算。
```

四节点配置在 `Network/four_bus_five_corridor.py`：既有 01、12、13，候选新建 02、23；保留原 L/M/H 设备、线路长度、造价、0.4 kV 电压、150 kVA 配变和 0.95 功率因数。默认预算为 20000、40000、60000 元和无限预算。主问题直接选择径向连接及型号，独立负荷为节点 1、2、3。

33 节点配置在 `Network/case33bw.py`：A–D、A–H、A–P 分别组成四、八、十六条嵌套候选集。节点 18、25、33 独立变化，其余负荷保持原始工况。32 条在运支路和五条常开联络线的状态不变。每条候选线路可保持原状或并联一回，R/X 减半；默认预算为 0、1、2 和无限，合成相对费用不是工程造价。

## 主线流程

1. 三个无预算 LP 轴向查询确定公共评价箱。
2. `joint_benders` 用逐线路 MP 与连续 LP/SOCP SP 查询最低投资或方向边界。
3. `build_region` 在同一评价网格中自适应分类，同时处理全部预算。
4. AC 阶段由 `ac_planning_query` 搜索建设方案，并用独立完整 AC 等式认证。
5. 保存结果，计算 FR/MR，生成四档预算的可旋转三维对比图。

纯线性和纯 SOCP 使用同一联合割流程。混合方法先运行自己的 LP 阶段，再用有效 LP 外割和建设初值开展 SOCP 查询；LP 内点必须重新认证。各方法从自己的数据开始，总耗时包含本方法全部阶段。

主 Notebook 不导入 tests，不运行模型审核，不创建看门狗进程，也不保存逐查询日志。求解器自身时限保留在 `model.py`；没有证书时返回未确定，不能认作不可行。Codex 测试可由 `tests/watchdog.py` 从外部限制函数运行时间。

## 结果与精度

输出目录由网架自动确定：四节点为 `results/four_bus_five_corridor/planning_5/`，33 节点为 `results/case33bw/planning_4/`、`planning_8/` 或 `planning_16/`。每次实验仅保存一个 `result.npz`，包含：

- `states`：方法 × 预算 × 三维网格，1 为域内，−1 为域外，0 为未确定。
- `metadata`：网架配置、预算、评价箱、源码指纹、公共准备时间和每种方法的总耗时。

不保存完整建设方案表、逐点日志、重复掩码或派生指标。FR/MR 和差异颜色都从相同标签现场计算。方法耗时覆盖其全部预算，在不同预算的表格行重复显示，不能相加；公共评价箱的准备时间单独记录。图形导出不计入求解时间。

红色为遗漏，黄色为多余，蓝色为重合，灰色为未确定。未知标签存在时仅报告保守 FR/MR 区间。完整分类表示网格中心全部获证，不表示连续边界已精确求出。

区域成块推断仅适用于当前非负纯负荷、正阻抗、根电压固定的径向网。引入分布式发电、反向潮流等破坏单调性的设置时，需要更换区域搜索方法。

四节点五走廊的网架与基础测试保留在正式代码中。已删除的是旧建设组合表、逐方案构域、枚举核对、旧回放及其归档程序。历史结果和说明文档保留作记录；旧 NPZ 格式不再由新入口兼容读取。
