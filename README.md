# 配电网规划—可调度域

四节点五走廊算例：节点 0 为电源，节点 1、2、3 为负荷节点；三个节点负荷非负、自由分配。
不设置分区基准、区内映射或增长比例。建设方案逐一确定可调度域，预算内各方案取并集。

## 文件

- `Network/`：网架节点、走廊、升级设备、费用和电气参数；当前算例名为 `four_bus_five_corridor`。
- `model.py`：MP1、MP2、SP 模型及割的添加。
- `region.py`：候选域、对偶割、同方案认证、并集扣除、局部凸块与选点队列。
- `plot.py`：Benders 图、费用前沿、三维并集表面及交互绘图；只读取求解状态。
- `replay.py`：从历史重建回放，打包多个预算，控制预算演变与逐轮播放。
- `NodePower.ipynb`：四个代码块，定义单独求解和协同求解流程。
- `results/four_bus_five_corridor.html`：自包含离线回放，汇集四档预算，播放不调用求解器。

## 规划域定义

节点负荷向量的顺序为 `network.load_nodes`，当前为 `(1, 2, 3)`。
每个节点均满足 $p_i\ge0$；允许 `(100, 0, 0)` 等极端分布，由电气 SP 判断能否实现。

对固定建设方案 $x$，令 $\mathcal F_x$ 为存在可行潮流、电压的节点负荷集合。
预算 $B$ 下的规划—可调度域为：

$$\mathcal D(B)=\bigcup_{x:\,c^Tx\le B}\mathcal F_x.$$

**不同建设方案之间只取并集，不把所有方案的可行点放入一个整体凸包。**
固定方案下采用线性电气模型，因而可用同方案 SP 可行点的凸包认证一个内域：

$$\mathcal I_x=\operatorname{conv}\{p:\text{方案 }x\text{ 下已通过 SP}\},\qquad
\bigcup_x\mathcal I_x\subseteq\mathcal D(B).$$

蓝色显示认证内域的非凸并集。迭代中可能遗漏尚未认证的可行部分；完整认证后得到该模型的完整规划域。
每个蓝色点至少存在一种预算内方案，不要求同一个方案实现整个蓝色区域。

## 四个代码块

1. **载入。** 导入网架和模块；重跑此块重置实验。更改网架后重启内核并重新载入。
2. **MP1SP。** 修改 `POWER`，求指定节点负荷的最低建设费用，输出 Benders 过程图。
3. **MP2SP。** 修改 `BUDGET`，求预算内最大总负荷，输出 Benders 过程图。
4. **协同求解。** `BUDGETS=(20000., 40000., 60000., np.inf)`，分别认证四个预算下的完整域，并导出一份回放。

`STEPS=1` 每次推进一轮，`STEPS=20` 每次最多推进20轮；`PAUSE=1` 两轮之间暂停1秒。
最后一块的 `STEPS` 对每档预算分别生效；演示使用10000轮上限、无暂停，完成后自动停止。
重跑相同代码块会续算。**达到轮数上限仅暂停，不代表完整域已经认证。**

```python
cost_query = MP1SP(np.array([100., 0., 0.]))
cost_query.run(100, 0)
cost_query.result

load_query = MP2SP(40000.)
load_query.run(100, 0)
load_query.result
```

单独求解的 `result['power']` 就是节点负荷，不重复保存一份同值的 `node_power`。
`studies[20000.]` 等对象保留各档预算的求解状态；`cooperative` 指向预算列表的最后一档。

## MP1、MP2 与 SP

MP1 最小化建设费 $c^Tx$。默认固定节点负荷向量；`total=True` 只要求 $\sum_i p_i\ge P$，允许自由分配。
因此，总量 MP1 返回的是至少一种分配达到指定总量所需的最低费用，不保证所有分配都能以该费用实现。

MP2 在 $c^Tx\le B$ 下最大化 $\sum_i p_i$；无限预算仅取消建设费用约束。
两类主问题均包含节点负荷非负、配变容量、树结构和累计割。
树结构用单商品虚拟流保证连通，并选择 $n-1$ 条边。

SP 固定 $(x,p)$ 后求：

$$\min_{w,\eta\ge0}\eta,\qquad Ww-r\eta\le h+Tx+Dp.$$

当 $\eta>10^{-8}$ 时，由 $\pi=-\mathrm{Pi}$ 添加可行性割：

$$\pi^T(h+Tx+Dp)=\beta_0+\beta_x^Tx+\beta_p^Tp\ge0.$$

SP 采用固定功率因数0.95、无损有功平衡和线性平方电压降。
当前配变为150 kVA，有功上限142.5 kW；结论针对这一线性模型。

## 完整切割过程与停止规则

每档预算独立沿用同一流程：MP2SP → 总量 MP1SP → 预算降低一个费用粒度（当前20元），恢复费用前沿。
已收敛 MP2 的最大总负荷同时收紧相应预算内方案的候选域。
随后搜索各方案候选域中尚未被任何方案认证的部分：

$$\mathcal R_x=\mathcal U_x\setminus\bigcup_y\mathcal I_y.$$

1. 对候选域先作单个认证凸域的快速包含判断；否则逐个扣除认证域，实现真正的并集覆盖判断。
2. 扣除产生的局部凸块放入优先队列，按维数、体积（退化时面积或长度）、最大总负荷排序。
   未更新条目的大小是剩余贡献的上界；只有排到前面时，才应用新割、新认证域并重新排队。
3. 选中一块后先检查未覆盖顶点，再检查与已认证域相交产生的边界顶点，块内按总负荷降序。
   已被其他方案认证的交界点仍可用于证明本块在当前方案下整体可行；不会把跨方案顶点直接连成凸包。
4. 固定 $(x,p)$ 后直接调用原 SP。可行点加入同方案认证凸包，继续完成当前块；
   不可行时将参数化对偶割应用到各方案外域，当前块收缩后重新排队。
5. 队列耗尽且当前块已获证时自动停止：每块都已被有效割删除或被认证并集覆盖。
   不以体积很小、没有新割、所有顶点已被不同方案分别覆盖作为停止条件。

块内连续认证避免每新增一个可行点就重新分割，减少碎片和重复检查。
交点只在去重时使用舍入键，实际坐标保留原始精度，避免破坏共面性。
`region.GEOMETRY_TOL=1e-7` 为单位法向量下的覆盖距离容差，单位 kW；完整认证指该容差内的结果。

两个阶段都遵循“本轮求解 → 应用割/总量上界 → 同方案认证 → 选择下一查询”的顺序。
外域切割和内域认证从前沿阶段就交错发生。MP1SP、MP2SP 和 SP 的数学模型保持原样；
仅在顶点阶段省去变量均已固定的 MP1 重建。绘图不参与选点与停止判断。

初始候选域为 $p\ge0,\ \sum_i p_i\le142.5$ 的单纯形。
SP 割保留建设变量，对不同方案分别切割；不能因某方案失败而从所有方案中删除同一个负荷点。
只有同一方案的可行点能组成认证凸域，各方案之间始终只取并集。

`model.py` 定义模型，Notebook 控制迭代，`region.py` 更新域；`replay.py` 从同一份历史调用域函数重建过程，不重新调用求解器。
MP1/MP2/SP 随非根节点数定义负荷变量；当前三维几何要求三个负荷节点，完整方案枚举仍用于小网架。
