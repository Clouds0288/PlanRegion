# 图形检查

用途：单一江口工况的算法验证，比较连续切割内域、尚未排除的外界与独立 AC 数值参考，不作为实测结果或全局 AC 最优性证明。

- 主图保留完整二维范围，两个坐标均为建筑总有功负荷，单位 kW；其余负荷固定。
- 灰色表示全局外界中的未确定部分，不能解读为已证可行。不同建设方案的内域取并集，不跨方案取凸包。
- AC 绿色边界对应全最大型号这一具体方案；橙线另施加 95% 额定电流阈值。
- 主图显示全部域；局部图只显示标明的窗口，明确注明两轴比例不同。导出的局部矢量路径也裁剪到该窗口，避免依赖阅读器裁剪造成误判。
- 展示已有可行证书方案的割外域并集；完整候选方案外域仍保存在 JSON 和顶点表中。
- Python/Matplotlib 绘制，画布 183×150 mm，PNG 为 300 dpi 浏览预览，另有 PDF 和可编辑文字的 SVG。未要求投稿 TIFF；不将 PNG 称为投稿原稿。
- PDF 最小字体 7 pt；单面板图不涉及多面板对齐。所有绘图数据来自保存的计算结果，无示意或模拟替代数据。
- 静态宽度检查把 `183/25.4` 误读为英寸；实际导出宽度为 183 mm。300 dpi 和未导出 TIFF 的提示适用于投稿检查，在本次预览用途下接受。
- 最终交付前重新执行 PDF 文字和碰撞检查，并人工查看主图与局部图。检查结果保存在同目录 JSON。

面积来自连续多边形或明确标注的 101 条 AC 射线折线近似；网格点数不代替连续面积。100×100 网格步长约 4.05 kW，可能跳过窄边带，因此同时保留顶点和射线检查。

最终复核通过：主图及局部图碰撞检查均为 0 fail / 0 warn；PDF 字体均不小于 7 pt；人工查看确认坐标、图例、边界与未确定区域清晰。局部图额外显示点、线形式的退化内域证书，连续面积只计二维多边形。
